# AI 适龄与工具事实核查

核查日期：2026-10-10。本文件保存资料和事实边界；候选游戏方案见[游戏方案比较](../游戏方案比较.md)。

## 工具名称与模型效果

- 用户口述工具名可能是 Cursor 和 TRAE，尚未确认。若确是二者，更准确的类别是 AI 开发工具，而非模型本身。
- Cursor 官方说明 Agent 由指令、工具、模型组成，并会针对模型调整指令和工具。可据此理解同名模型的使用环境可能影响实际效果；不能据此认定平台普遍使模型降质。
  来源：https://cursor.com/docs/agent/overview
- 规则、系统指令、上下文处理等是实际机制；它们对某项任务的影响方向和大小需要具体验证。
  来源：https://cursor.com/docs/agent/prompting
  来源：https://cursor.com/docs/rules
- TRAE 中国版官方说明规则及多模型机制，但不能据此推断同事使用的国际版、版本、实际模型和配置。
  来源：https://docs.trae.cn/ide_rules
  来源：https://docs.trae.cn/ide_models
- 楠关于审美、产品思维、个人偏好与模型降质的描述应保持为用户观察或假设；尚未审阅同事作品，不应作独立能力评价。

## 六岁孩子接触 AI 的资料边界

- Anthropic 消费者条款规定至少 18 岁，并限制把账户提供给他人。成人陪同不能被当成六岁孩子直接使用消费版的年龄例外。最终选产品时需再次核查有效条款。
  来源：https://www.anthropic.com/legal/consumer-terms
- Anthropic 对服务未成年人的 API 产品提供独立指引，包括适龄措施和说明 AI 身份；安全提示词不能替代应用自己的措施。页面日期为 2026-03-16。
  来源：https://support.claude.com/en/articles/9307344-responsible-use-of-anthropic-s-models-guidelines-for-organizations-serving-minors
- OpenAI 官方 API 未成年人指引要求额外适龄保障；处理 13 岁以下儿童个人数据前需实现 API 零数据保留等要求。这是 API 场景指引，不能用它推出 ChatGPT 消费版的年龄许可。
  来源：https://developers.openai.com/api/docs/guides/safety-checks/under-18-api-guidance
- UNESCO 2023 指南建议独立与通用生成式 AI 平台对话最低年龄为 13 岁。这是机构建议，并非普遍适用的法律，也不能作为六岁成人陪同直接聊天的效果证明。
  来源：https://unesdoc.unesco.org/in/rest/annotationSVC/DownloadWatermarkedAttachment/attach_import_59752630-3c8b-464e-8f23-013d99a9dd67?_=386693eng.pdf&from=1&to=48
- UNICEF 2025-05-23 的文章指出儿童与 AI 聊天的认知、社会、情绪影响，尤其长期影响，仍缺乏充分了解。不能承诺 AI 对话提升六岁孩子的逻辑或独立解决问题能力。
  来源：https://www.unicef.org/innocenti/stories/beyond-algorithms-three-signals-changing-ai-child-interaction
- 后续评估应区分认识 AI、成人使用 AI 制作内容、儿童与受限功能交互、儿童直接使用通用消费者聊天账号。各项是否采用尚未决定。

- 已确认平板、可联网、主线需支持独立玩，陪伴可选；不再重复询问这些条件。
