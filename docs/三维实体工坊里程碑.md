# 三维实体工坊

状态：实现与自动验收通过，真实试玩待确认。用户在位置开垦修正完成后的下一任务选项中明确选择“三维实体工坊”。

## 范围

默认工坊入口进入三维工作台近景：桌面有实体插槽，前方有木料/木板/木棍托盘，旁边有产物展示位和木拉杆。拖材料进槽，点实体产物选结果，再拉动杆制作；图卡可演示摆法，保留原二维格子入口和键盘/点击备用路径。

采用独立、按打开/关闭创建销毁的工作台近景渲染器，不重写河谷世界或引入物理引擎。它是工坊操作视图，不是模型中自由行走。场景模型为程序化木制工作台与既有物品，配方仍是既有游戏约定，不增加新材料或任意物品配方。

## 用户验收

打开实体工坊 → 拖一份木料进实体槽 → 看右侧木板结果 → 拉木拉杆 → 木板在展示位出现且背包增加4、木料减少1 → 回到河谷可建造 → 再打开可自由试摆。

界面里的拉杆和快进制作不是现实锯切/切削教学。加工说明与普通材料来源保持原样；不要求答题或付费，没有新工具/等待门槛。自行车、轮轴、蓝图、批次谱系、新区播种继续留在待办，不混入本轮。
