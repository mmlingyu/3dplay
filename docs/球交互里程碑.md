# 里程碑：木球可持续交互

## 状态
自动验收通过，等待真实设备手感试玩；用户已选择球滚动与推动作为本轮唯一功能。

## 目标
把短暂的木球试验升级为可以下坡、推动、停下再推及取回的持续玩具，为后续轮子与载具提供小规模物理验证。

## 范围
木球滚动、角色接触推动、停止/唤醒、边界拦截、明确回收和兼容旧世界的可选球存档字段。沿用可复用玩具规则与最多四球预算，不新增球材料。

## 范围外
自行车、游泳、季节、工坊改造、扩图；完整刚体/关节/软体模拟。其他方向见 `backlog.md`。

## 验收
- [x] 坡道滚动、平地减速、超过 13 秒仍存在、角色推动后继续滚、暂停不运动、取回释放名额。测试：`test/ball-check.js`。
- [x] 保存与刷新恢复球，不推进离线运动；无球字段的 v1 世界仍可读；错误球字段不替换当前世界。测试：`test/ball-check.js`、`test/game-state.test.js`。
- [x] 电脑与触屏放置操作不回归。测试：`test/placement-gestures.js`、`test/placement-check.js`。
- [ ] 真实设备推球手感。由用户试玩验证，未验证前不宣称完成。

## 退出条件
玩家放木球、用角色推它、停下再推并取回，观察到可重复的球交互；自动验收通过，手感交还用户验证。

## 检查方式
先写失败用例，随后运行 `npm test`、球浏览器检查、放置检查、原流程与 `npm run build`。球场景用独立浏览器上下文，输出只在系统临时目录，不覆盖真实存档。
