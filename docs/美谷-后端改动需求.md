# 美谷后端改动需求

日期：2026-10-20。本文只记录 IdeaLab 后端需要的接口和存档兼容。本仓库是 3dplay 游戏前端，不包含 FastAPI、`knowledge_tutors.py` 或 `valley_store.py`。没有后端时，前端用浏览器本地存档和 `src/mei-tutors.js`，美谷仍可采集、熬糖、做项目、拼布、盖章和回家。

## 知识接口

### 已有接口不要改行为

- `GET /api/knowledge/tutors` 不带查询参数时，响应仍只包含河谷角色（`valley` 缺失或为 `he`）。不要把美谷或日谷角色混进去。
- `GET /api/knowledge/tutors?valley=ri` 仍只返回日谷角色。失败时前端继续用本地日谷包。

### 按谷读取美谷

`GET /api/knowledge/tutors?valley=mei` 返回美谷角色包。失败、空列表或过滤后没有角色时，前端改用 `src/mei-tutors.js`，不阻断渡船、热气球、采集、熬糖、项目板或回家。

可选：`GET /api/knowledge/valleys` 列出谷 id、显示名和是否可玩。本版前端不依赖它。

### 建议的角色字段

美谷内容不要写进河谷 `valley-tutors.json`，也不要写进日谷包。单独存放，并带这些字段：

- `valley`：`mei`。
- `subjects`：至少 `lang-en`（英语）和 `craft`（手工）。
- 年龄档：`little`（4–6）、`bigger`（7–9）、`older`（10–12）。`older` 没有题目时，前端按 older → bigger → little 回退。
- 选项可带 `audio`。英文句子和中文分开。
- `ref`：知识句需要出处。当前本地稿使用的公开条目：
  - 莱特兄弟首次动力飞行：https://www.nps.gov/wrbr/learn/historyculture/theroadtothefirstflight.htm
  - 黄石国家公园 1872：https://www.nps.gov/yell/planyourvisit/parkfacts.htm
  - 史密森尼感恩节食物条目：https://www.si.edu/spotlight/thanksgiving/thanksgiving-foods
  - 爱荷华州推广站枫糖（约 43 加仑树汁对 1 加仑糖浆）：https://naturalresources.extension.iastate.edu/forestry/forest_products/syrup.html
  - 阿波罗 11 任务概述里的一句英文，只做成大孩子卡片，不是新玩法：https://www.nasa.gov/history/apollo-11-mission-overview/
- `review.status`：英文在母语者审阅前保持 `draft`。
- `published: false` 的角色不要下发。本地包里的 `draft-hidden` 就是这种角色，前端会滤掉。
- 题目不是门槛。答对只由前端发 2 份枫树汁和一张贴纸，不发印章。接口不要把题目做成地图、配方、项目板、印章或时长的开关。

角色是 Maya、Will、Orv、Rivera、Joe。Orv 的说明必须能表达“以真实历史人物为原型的游戏角色”。Joe 带着桶（`prop: bucket`）。现有 NPC 外观枚举如果已经允许 `bucket`，不用改枚举。

管理端的知识列表需要能按 `valley=mei` 筛选。本仓库没有管理界面，这一项留在后端。

## 存档

`valley_store` 必须继续接受 v1 存档。不要因为多了 `travel.realms.mei` 拒绝整份快照，也不要因为没有美谷字段清空河谷或日谷。

前端约定：

- 主 key 仍是 `yuanyuan-river-valley-v1`，`version` 仍是 `1`，`travel.schema` 仍是 `1`。
- 美谷只写在 `travel.realms.mei`：玩家、方块、箱子、标记、加工、项目卡、交换记录、南瓜灯表情。河谷的方块、背包、园地和日谷记录留在原来的位置。
- 第一次把一份还没有 `travel.realms.mei` 的原文写成带美谷的存档之前，前端把**原始字符串**写入 `yuanyuan-river-valley-v1-before-mei`。已有不同备份时用数字后缀。备份写不回去就不覆盖主 key。已有空的 `realms.mei` 的新世界不再写这份备份。
- 导入整份文件时，不合法的美谷字段会拒绝整个文件。本地加载则保留原文，坏掉的美谷记录退回河谷，家里的建筑、背包和日谷不动。
- 新物品 id 会让不认识这些 id 的旧前端拒绝新存档。服务端不要为此把版本号改成另一套。这些 id 是：`maple-sap`、`maple-syrup`、`log`、`log-wall`、`cloth`、`quilt-patch`、`quilt`、`paper`、`axle`、`paper-plane`、`windmill-mini`、`pumpkin`、`pumpkin-lantern`、`thanks-card`。
- 客户端导入上限仍是 500 万字符，文件选择约 2 MiB。美谷方块上限 600，项目卡上限 20。账号同步的单份 JSON 配额要按这个上限留余量，不要按“只有河谷方块”估算。本仓库不改服务端配额。

## 本版前端已经做的降级

- 美谷角色、英文草稿和出处在 `src/mei-tutors.js`。知识快照 id 在 `knowledge/valleys/mei.json`。
- 录音文件还不存在。缺的 id 是 `en-hello`、`en-sun`、`en-tree`、`en-friend`、`en-build`、`en-cat`、`en-measure`、`en-test`、`en-fix`、`en-change`。前端不在启动时播放。
- 英文均为草稿，待母语者审阅。不要把本地稿当成已审定课文。
