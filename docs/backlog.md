- [x] 球类滚动与角色推动：球在自建坡道上滚动，角色接触能推球，静止球可再推动，不因短倒计时自动消失。已进入[球交互里程碑](球交互里程碑.md)；自动验收通过，真实设备手感待试玩。

  - 本轮结果：木球已可推动、再推动、主动取回、边界拦截和存档恢复；旧 v1 无 `toys` 字段仍可读取，不新增其他材料球。

- [x] 入水与游泳：进入足够深的水域后切到游泳移动、划水/踢腿和出水过渡；桥上或浅水不误判。已进入[游泳里程碑](游泳里程碑.md)，自动验收通过，真实设备手感待试玩。
  - 来源：2026-10-15 用户第 2 项。
  - 规模：M；价值：中高。
  - 说明：当前是浅溪，需判断深度和角色浸没状态，不将所有接触水都视为游泳；是否新增深水池待设计。默认不加入溺水惩罚或把游戏动作当游泳教学。
  - 本轮结果：原浅溪/桥面不变，新增带坡道的高位泳池 `(0,11)`，深水浮起、划水/踢腿、减速与上岸动作通过检查；预定区域有旧建筑时不生成池体，存档格式不变。
