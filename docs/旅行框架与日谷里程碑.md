# 旅行框架与日谷里程碑

日期：2026-10-20。这是前端仓库里的 P1：同一份河谷存档上的旅行框架，加上可玩的日谷。美谷、外星谷只保留 id，没有地图和角色。

## 做了什么

- 河谷仍是孩子自己的家，不标国家，不加国家建筑或节日。日谷是固定的外谷，不是关卡。
- 小溪下游有渡口。预定格子上如果已经有自己的建筑，渡口换到另一处，不覆盖旧作品。点“去日谷”后有一段可跳过的过场；暂停或页面隐藏时过场不计时。任何打开的面板也会让这段过场停住，比“只在暂停菜单停”更严。
- 日谷里有纸坊、一栋陡茅草的合掌样式房子、楮树林、竹林、小溪、鼓桥、访客小院和热气球草坪。角色是小春、楮叶奶奶、狸猫阿哲，穿日常衣服。预写台词，没有实时对话。
- 楮皮可以采集。和纸分五步，大约 20 秒：剥皮蒸煮、敲打成纤维、加水、竹帘抄纸、晾干。看面板时继续；暂停或不调用 tick 时不走；页面隐藏时整帧不走。
- 纸鹤用一张和纸。纸船用两张并排。纸鲤鱼旗用和纸加竹篾。纸拉门用和纸加木棍。格子分成这样，是为了每种左边材料组合只对应一样结果。真实折纸通常一张纸、很多步，说明写在折叠段落里。
- 印章：到达日谷、第一张和纸、第一只纸鹤、帮小春修鲤鱼旗。渡口、航线、采集、配方、印章和纪念品都有不答题的做法。答题在“看一看 / 做手工”之后，只给 2 份楮皮或贴纸，答错不扣。第一次见面不自动出题。
- 访客小院可以摆放。朋友的家和园子会显示红色原因，不能盖。家里的方块不跟着外谷改。
- 热气球原有的起飞、转圈、自己开、降落还在。空中多了“看风景去日谷”，文案写明路程和天气被简化。航行中刷新回到出发草坪，不留在半空。
- 日谷信箱有一封可以关掉的画。关掉后记在 `travel.story.seen`，不挡住渡口。
- 暂停菜单可以选 4–6、7–9、10–12 或不设置。这是对话默认长短，不记录生日。10–12 岁没有题目时用 7–9 岁，再没有就用 4–6 岁。未发布角色不出现。
- 离开河谷或日谷时释放场景监听，并 `dispose` 渲染器。不再调用 `forceContextLoss()`，否则同一块画布无法再创建 WebGL。
- 后端不在本仓库。拿不到 `?valley=` 或接口失败时，日谷用 `src/ri-tutors.js`。需要的接口写在 [日谷后端改动需求](日谷-后端改动需求.md)。

## 存档

主存档键 `yuanyuan-river-valley-v1`，版本 1。只增加可选的 `travel` 和 `settings.ageBand`。

第一次覆盖一份还没有 `travel` 的存档之前，把当时的原文写到 `yuanyuan-river-valley-v1-before-travel`，读回再比。已有不同备份时用数字后缀。备份失败就不写主存档。重复进入不会再写第二份相同备份，也不会重复发初始物品或印章。

导入的文件如果 `travel` 不合法，整份拒绝。本机读取时：只有位置出界就留在日谷、回到码头；外谷数据不合法就回河谷，家里的建筑和背包不动，并在暂停菜单提示。家里的数据如果也坏了，原来的损坏存档保护优先，不用旅行修复替换它。

新物品 id 会让旧前端拒绝新存档。说明在 README 的存档一节。

## 知识与日语

本地日谷包里的日文都标了 `review.status: draft`，等母语者审。读音写在单独字段。用字和简体中文分开，例如「気」不是「气」。

依据：

- 和纸工艺：UNESCO，传统手漉和纸，https://ich.unesco.org/en/RL/washi-craftsmanship-of-traditional-japanese-hand-made-paper-01001
- 合掌造：UNESCO 世界遗产名录 734，https://whc.unesco.org/en/list/734
- 平假名：Britannica hiragana，https://www.britannica.com/topic/hiragana

待录音的 id：`ja-konnichiwa`、`ja-arigatou`、`ja-oyasumi`、`ja-sakura`、`ja-yama`、`ja-kawa`、`ja-aiueo`。现在只有占位，没有音频文件。

待审日文：こんにちは、ありがとう、おやすみ、さくら、やま、かわ、あいうえお、気。
