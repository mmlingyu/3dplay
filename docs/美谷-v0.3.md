# 美谷 v0.3 片场

日期：2026-10-21。农场仍在，旁边加上黄金时代片场。这些是脚本和 Chromium 视口里的自动检查，不是孩子试玩，也不是真实平板。

## 场景

- 山坡大字写 USA。星光步道按已有美谷印章和孩子做过的东西点亮，最多八颗。
- 拱顶摄影棚、装饰艺术风格的星光大影院、街景布景和西部布景。两处布景都能绕到背后看见木头架子。没有枪，没有决斗。
- 中景有红色吊桥和举灯的灯塔兔。兔子是圆耳朵、短背心、方灯，不像自由女神。
- 坐大船时，过场和进港的船从吊桥下面穿过。远眺只改美谷：大字加吊桥，夜里有探照灯。
- 角色按少年比例。片场里另有摄影机机器人咔嚓、浣熊导演 Rudy。南瓜头只有笑脸、猫脸、星星。

## 学习与故事

- 6–8 岁（含原来的 4–6 和 7–9）：Action、Cut、三格分镜。
- 9–12 岁：远景、中景、特写，每秒 24 帧对比，三点布光。一次只改一盏灯。
- 英语和中文用生成的语音，地址在 `/audio/mei/`，并随 `VITE_BASE`。播放失败时用 `speechSynthesis`。
- 和 Will、Orv、咔嚓修好放映机（齿轮、镜头、灯）后写入 `travel.realms.mei.storyShard = true`，盖章「首映」。然后可以看一段星空和飞船，也可以跳过。没有先做序章也能拿到。不写 `travel.story`。
- `?tour=1` 时放映机只缺旁边的灯。读取写在 `src/mei-lot.js`。
- 星光首映夜放孩子自己的照片或小电影，不评名次。
