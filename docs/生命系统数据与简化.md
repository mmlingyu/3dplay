# 生命系统数据与简化

实现/核对日期：2026-10-15。第 3 项首期覆盖蒲公英与菜豆，不代表全部花草、树木、生态和植物传播已经完成。

## 游戏时间

`clock.elapsed` 是允许游玩时累计的整秒时间，不读取电脑日期。240 秒为一个游戏日，3 日为一个季节，春夏秋冬循环。日夜和季节都读同一个时钟。参数为游戏快进，尚未经孩子试玩校准，不是现实生长日历。

同日接续增加 1–12 卡通指针钟：从 06:00 开始，短时针/长分针映射24小时河谷日；06:00–18:00 白天、18:00–20:00 傍晚、20:00–06:00 夜间。此前按日内比例划分的傍晚区间已统一到钟面时间，避免凌晨仍显示傍晚。这是固定日长的游戏示意，未模拟纬度或四季日长。

查看工坊、菜园或观察面板时继续；暂停、未开始、隐藏或离线时不推进。恢复只读取已存状态，无离线枯死、额外损失或签到。夜景保留足够亮度，不增加操作门槛。

## 物种、实例和条件

规则与来源在 `src/life-data.js`；推进和校验在 `game-state.js`；表现读规则，不自行推算另一套年龄。

- 蒲公英：明确采用 `Taraxacum officinale` 的形态示意，保留叶丛、花苞、黄色花序与浅色种子头；冷季保留根/叶的游戏休眠状态。`flora.age` 是本次花序周期的成长秒，不是整株寿命。
- 暖季花序周期 240 秒，全日照每秒一步、半阴每两秒一步；上方建筑遮挡则暂停，取走后恢复。冷季不推进花序，进入秋季重置花序计时。速度差、季节开关和建筑遮挡均是近似，不模拟实际太阳光线、土温、养分和降雨。
- 开花阶段日间展开、晚间合拢；种子头不是立刻变为背包种子，没有凭空添加花种采集/播种链。自然传播、重新播种及更多物种仍待扩展。
- 菜豆保留原 90 秒适宜水分模型、积水排水/移栽、采收留种。菜园的光照和生长环境被固定为适宜，季节不会成为豆子生产门槛；不表示现实中仅靠浇水就能让菜豆在冬季露地生长。
- 草地的季节色调只是表现；树木、草地本身没有独立生长年龄。本期不把装饰变色宣称为完整生态。

## 科学来源与边界

2026-10-15 检索到的公开资料：

- [RHS：Taraxacum officinale](https://www.rhs.org.uk/plants/232327/taraxacum-officinale/details)：多年生草本、基生叶、主根、黄色花序和浅色种子头。
- [RHS：Taraxacum officinale agg.](https://www.rhs.org.uk/plants/76282/i-taraxacum-officinale-i-agg/details)：叶丛、齿状叶缘、空心花茎及英国环境的开花月份。游戏叶片和叶缘是低多边形近似，未逐齿刻画。
- [Maryland Jefferson Patterson Park：Dandelion](https://jefpat.maryland.gov/Pages/education/plants/dandelion.aspx)：日间开放、晚间合拢的花序。

来源支持上述形态特征，不支持游戏秒数、全球统一四季、半阴恰好减半、所有地区冬季相同休眠或教育效果。没有将食用/药用内容纳入儿童玩法。

## 存档与恢复

仍使用原主 key 和 `version=1`。新增可选 `clock`、`flora` 字段；缺少时默认从春季零秒、叶丛阶段开始，不清理旧库存、建筑、球、人物、园地或砖窑。完整新字段校验非法值、物种、ID、数量和花序年龄。

加载旧世界、第一次写入新字段前，会保留原始有效 JSON 到 `yuanyuan-river-valley-v1-before-life`。若已有不同原文，依次用 `-1`、`-2` 等后缀保留，不覆盖已有备份；写入读回失败则不覆盖原主 key。最多尝试 100 个槽位，满额提示导出。

暂停菜单“给大人：备份与导入存档”可下载本次升级前备份；重新打开浏览器后默认提供首份基础备份。其它带后缀的备份仍在同一网站的本地存储中。恢复时用原有导入确认流程，导入前也能下载当前世界。无云端同步，不跨网站来源。

## 验证与后续

`npm test` 验证时钟、暖冷季、个体条件、菜豆兼容、旧存档和备份保护。`test/life-check.js` 验证面板同步、暂停/模拟隐藏、刷新、冬季、增量模型和响应式界面。模拟隐藏是测试可见性分支，不是实际平板后台实测。

今后增加物种应先提供知识来源、物种配置、普通来源与繁殖链，再实现行为和模型，不能仅换名字或颜色。扩图与二维图卡/拖放工坊首期已接续实现，见 `时钟开垦与工坊迭代.md`；新区草地发现没有接入个体生命，菜园仍六格。装配/骑行体系只有专门设计交付，不因生命规则数据化就宣称未知物品引擎已完成。
