# 外星谷后端改动需求

日期：2026-10-20。本文只记录 IdeaLab 后端需要的接口和存档兼容。本仓库是 3dplay 游戏前端，不包含 FastAPI 或知识库服务。前端在接口不可用时使用仓库内的 `src/xing-tutors.js` 和 `src/glyph-data.js`，外星谷仍可游玩。

## 知识接口

### 不带参数的旧接口必须保持原样

`GET /api/knowledge/tutors` 不带查询参数时，响应必须与旧客户端的快照一致：只包含河谷（`valley` 缺失或为 `he`）的角色。不要把外星谷或日谷角色混进这份响应。

### 只按谷读取外星谷

`GET /api/knowledge/tutors?valley=xing` 返回外星谷角色包。失败、空列表、超时，或过滤后没有角色时，前端改用本地包，不阻断热气球、采集、试验、盖章或回家。

`published === false` 或 `review.published === false` 的角色不要下发，前端也会再丢掉。本地稿里有一条 `draft-xing` 就是这样，用来确认未发布内容不会出现。

年龄档：`little`（4–6）、`bigger`（7–9）、`older`（10–12）。`older` 没有题目时按 older → bigger → little 回退。

建议字段与日谷相同，并加上：

- `valley`：`xing`。
- `subjects`：`logic`（逻辑）、`science`（科学）、`math`（数学）。
- 角色：小咕（`style: alien`，四指，逻辑）、晶晶博士（`prop: lens`，科学）、零一（`style: robot`，数学）。不要用现实族群的服饰、肤色或口音表示“外星”。
- `review.status`：审阅前保持 `draft`。
- 科学题可以带 `ref`。重力对照用的是 NASA Glenn 的重量说明（火星表面重量大约是地球的三分之一）和 NASA 的月球数字（大约六分之一，只作对照，不拿来当外星谷的重力）。罗塞塔石牌说明用大英博物馆的介绍（同一篇诏书有圣书体、世俗体和古希腊文；商博良 1822 年 9 月 27 日公布读法）。四进制题不要附月球链接。
- 符号的形状、种子和四进制换算留在前端 `src/glyph-data.js`，不要放进可编辑的知识包。知识包只放角色台词和可选题目。

一份与本地包一致的草稿在 `knowledge/valleys/xing.json`，给后端接入时对照。前端运行时不读取这个文件。

## 存档

`valley_store` 必须接受带 `travel.realms.xing` 的 v1 存档，也必须继续接受没有这个字段的旧存档。不要因为多了 `xing` 拒绝整份快照，也不要因为没有 `xing` 清空河谷、日谷或美谷。

前端约定：

- 主 key 仍是 `yuanyuan-river-valley-v1`，`version` 仍是 `1`。外星谷数据只在 `travel.realms.xing`（玩家、方块、箱子、已声明、加工、`glyphs`、`puzzles`、`experiments`）。不改根字段，不改 `realms.ri` 和 `realms.mei`。
- 第一次把一份还没有 `travel.realms.xing` 的原文写成带外星谷的存档之前，前端把**原始字符串**写入 `yuanyuan-river-valley-v1-before-xing`，读回再比。已有不同备份时用数字后缀。备份写不回去就不覆盖主 key。新游戏没有旧原文，不写这份备份。
- 美谷如果还不可玩，`realms.mei` 按原文保留（有长度上限），不要在校验外星谷时丢掉它。
- 导入整份文件时，不合法的外星谷记录、或家里的方块/菜园里出现“幻想且活着”的物种，整份拒绝。本地加载则把坏掉的外星谷记录退回河谷，家里的建筑和背包不动。
- 新物品 id（`salt`、`salt-crystal`、`meteorite`、`glowmoss`、`glowmoss-case`、`glass-dome`、`glyph-plaque`）会让不认识这些 id 的旧前端拒绝新存档。服务端不要改版本号来伪装兼容。

客户端导入上限是 500 万字符，文件选择约 2 MiB。盐晶加工大约 20 秒，离线不补进度。存储配额按整份 JSON 估算。

## 本版前端已经做的降级

- 角色和题目在 `src/xing-tutors.js`。符号规则在 `src/glyph-data.js`。
- 知识接口 800 毫秒内没有成功响应就继续用本地包，不弹出连接失败。
- 录音文件还不存在。缺的 id 是 `xing-gugu-hello`、`xing-crystal`、`xing-lamp`。前端不在启动时反复播放。
- 文案均为草稿。不要把本地稿当成已审定课文，也不要把它说成已经在孩子或真实平板上验证过。
