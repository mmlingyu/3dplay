# 可拆轮轴试装台

状态：阶段一实现与自动验收通过；真实设备与儿童试玩待确认。范围来自用户的分阶段要求：“先做可拆装轮轴并验证轮子能独立转动，再做一辆明确标注稳定规则的可骑载具，最后加入作品保存、重载和拆解。”

## 已实现范围

- [x] 河谷内新增“轮轴试装”实体目标，可从场景打开试装台。
- [x] 左右轮各有对应插槽；插接关系以独立状态记录，错误插槽、重复连接和空位拆卸会被拒绝。
- [x] 点击/按钮可安装或取下轮子；桌面可在三维画布中拖动已安装的轮子，触屏与键盘辅助操作可用大按钮。
- [x] 各轮角度独立更新。转动左轮不改右轮角度，也不改变固定轴；右轮同理。读数显示连接数量和三者角度。
- [x] 关闭试装台会释放渲染循环、事件监听、几何体、材质与 WebGL 上下文。
- [x] 试装为临时演示，不改库存、建筑和存档；未新增材料、配方、加工来源或作品实例。
- [x] 测试覆盖连接、错槽、拆装、非法步进、独立转动和关闭状态；桌面/平板浏览器流程覆盖实际场景入口、按钮与画布拖动、触屏目标尺寸、背包/建筑不变和资源释放。

## 明确规则

这里用固定轴和两个独立转动接口演示“轮子可连接、可拆开、可各自绕轴转动”。这是游戏内的机构原型，不模拟真实轴承结构、材料强度、承重、传动、碰撞或骑行。试验架零件是演示件，不会被计入背包，也不是已加工的木制轮轴。
