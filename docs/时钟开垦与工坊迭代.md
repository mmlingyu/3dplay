## 实现范围与试玩入口

新世界使用固定初始种子，当前默认宝箱可给木板/工作台/储物箱；斜坡奖励在其他有效种子配置中覆盖，不保证每类奖励在每个世界都出现。每新区一个发现点；小兔仅简化动作，草地发现不接完整成长。新区种植、三维开垦工具、远处卸载与完整动物生态未完成。

试玩：打开运行中的5174预览 → 用方向键或摇杆走到开放草地边缘 → 出现“前面还没整理，想去看看吗？” → 点“开垦这里”（或“先不”）→ 新区出现后走过去领取发现 → 刷新后再点不重复发奖。小地图面板只提供身边可开的地块，远程只有引导。远距离自动走近发现仍是直线，受障碍阻挡时可摇杆手动过去。

截图在系统临时目录 `valley-clock-*`、`valley-craft-drag-*`、`valley-newland-*`、`valley-discovery-*`。自动检查使用独立上下文，不覆写使用者真实存档。首次理解和真实设备手感由用户试玩验收，不以自动通过代替。

最终补查：已实际查看手机小兔与宝箱场景截图；为了看清发现模型，截图时临时隐藏起步愿望卡与短暂提示，游戏本身未隐藏这些控件。电脑大图查看接口多次失败，但截图已生成、电脑交互断言通过，未修改网络配置解决图片接口故障。
