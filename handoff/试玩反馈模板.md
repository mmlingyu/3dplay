# 试玩反馈模板

版本日期：2026-10-14。每次复制一份，只记录一件最明显的问题和一项拟改进。用于产品迭代，不是能力测验或诊断表。

先让孩子自由选想做的事。成人无需预先安排全部活动；遇到停住时，先观察她是否自己尝试，再提供需要的帮助。允许她不做题、不参与实验、提前结束。记录真实发生的行为，不追求填满表格。

| 实体设备 / 浏览器模拟 |  |

不需要孩子姓名、班级、照片、健康资料或诊断信息。

## 把三种结果分开

本次只填自然发生的部分。没有出现就写“未观察”，不额外组织一轮考试。

| 观察层面 | 实际证据或“未观察” | 本次最多能支持什么 |
| --- | --- | --- |
| 题目与资源奖励 | 是否主动去补给站；是否看/听题目；领取后去做什么；也可记录主动不答题 | 愿不愿用这条路径获取材料，不能单独证明喜欢学习 |
| 知识或条件理解 | 是否自己预测、解释、比较或调整；例如指出水多后停止生长，改浇水/排水条件。注明有无提示 | 本次任务中是否表现出理解，不能单独证明长期掌握 |
| 现实迁移（可以后补） | 游戏以外的新情境中，是否自己用过类似办法；写场景、行为及提示。只复述游戏规则也注明 | 有没有迁移线索；没机会观察不等于不会 |
